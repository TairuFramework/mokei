## Commands

### `mokei chat`

Interactive chat with a model provider. One command handles every provider — if
`--provider` is omitted, an interactive selection prompt appears.

Usage: `mokei chat --provider ollama --model "llama3.1:8b"`

#### Flags

- `-p, --provider <name>`: model provider (`ollama`, `openai`, `anthropic` or `llama`)
- `-k, --api-key <key>`: provider API key. Prefer the `OPENAI_API_KEY` /
  `ANTHROPIC_API_KEY` environment variables — a key passed on the command line leaks via
  `ps` and shell history
- `-u, --api-url <url>`: provider API URL, overriding the default endpoint
- `-m, --model <name>`: model name, or a GGUF file path for the `llama` provider
- `-t, --timeout <seconds>`: agent turn timeout in seconds (default: `300`)

Inside the session, `/context add [--protocol <version>] <key> <command> [args...]` attaches
an MCP server. `--protocol` accepts `2026-07-28`, `2025-11-25` or `auto`, and defaults to
`2026-07-28`. Type `/` to list the other slash commands.

### `mokei inspect <command> [args...]`

Spawns a local MCP server and asks it to describe itself. On `2026-07-28` that is a
`server/discover` request; on `2025-11-25` it is the `initialize` handshake.

Usage: `mokei inspect npx -y @modelcontextprotocol/server-filesystem ./`

#### Arguments

- `command`: the command to execute to start the MCP server (required)
- `args...`: arguments passed to the command, forwarded as-is

#### Flags

- `-p, --protocol <version>`: protocol revision to speak — `2026-07-28`, `2025-11-25` or
  `auto` (default: `auto`). Must come before the server command; everything after the
  command belongs to the server

### `mokei monitor`

Start a local HTTP server serving the monitor UI, which tracks MCP client-server
interactions routed through `mokei proxy`.

Usage: `mokei monitor --port 4000`

#### Flags

- `-s, --socket-path <path>`: path to the socket used by the host daemon (optional)
- `-p, --port <number>`: port the HTTP server should listen on (optional)

### `mokei proxy <command> [args...]`

Proxy an MCP server so its traffic can be inspected in the monitor.

Usage: `mokei proxy npx -y @modelcontextprotocol/server-filesystem ./`

#### Arguments

- `command`: the command to execute to start the MCP server (required)
- `args...`: arguments passed to the command, forwarded as-is

#### Flags

- `-s, --socket-path <path>`: path to the socket used by the host daemon (optional)
