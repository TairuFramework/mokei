# MCP `2026-07-28` Subscriptions (`subscriptions/listen`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Stage:** executing
**Mode:** tasks

**Goal:** Implement MCP `2026-07-28` `subscriptions/listen` (SEP-2575) end to end — client receive, server serve, `@sozai/event` producers, host events — over stdio and Streamable HTTP.

**Architecture:** Every listen is served by a normal `ContextServer` via a new held-response primitive in `ContextRPC`; the durable server owns a shared `SubscriptionHub` (registry + producer fan-out) that per-POST transport-isolated servers borrow on stateless HTTP. The client models a listen as a stream exchange keyed on `subscriptionId == the listen request's JSON-RPC id`, fed by an optional notification correlator.

**Tech Stack:** TypeScript, pnpm workspaces, vitest, `@sozai/schema` (JSON Schema), `@sozai/event`, `@sozai/async` (`Disposer`/`defer`), `@sozai/runtime`, `@enkaku/transport`, hono (http-server).

**Spec:** `docs/superpowers/specs/2026-08-27-mcp-2026-07-28-subscriptions-design.md` — read it before starting; every task argues from it.

function routeSubscriptionNotification(notification: ServerNotification): { id: RequestID; frame: StreamFrame } | null {
  const meta = notification.params?._meta
  if (meta == null || !Object.hasOwn(meta, META_SUBSCRIPTION_ID)) return null
  const value = (meta as Record<string, unknown>)[META_SUBSCRIPTION_ID]
  if (typeof value !== 'string' && !(typeof value === 'number' && Number.isInteger(value))) {
