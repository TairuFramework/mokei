# Flow CLI and MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `mokei daemon|flows|runs|inbox` commands and a generic flow MCP server (`mokei flows mcp`) over the shared
daemon, replacing `scripts/flow-rig`, plus corrected published dependency declarations.

**Architecture:** New portable `@mokei/flow-client` holds the `FlowControl` interface, the daemon adapter, wait helpers
and the MCP `ServerConfig` factory. `@mokei/flow-host` adds an in-process adapter. The CLI only wires a remote
`FlowControl` into commands and `serveProcess`.

**Tech Stack:** TypeScript (NodeNext ESM), Enkaku client, `@mokei/context-server(-node)`, commander via
`@tejika/cli`, Ink with `@tejika/ui` and `@inkjs/ui`, vitest, pnpm 12, turbo.

**Spec:** `docs/superpowers/specs/2026-10-03-flow-cli-design.md`

## Global Constraints

- Branch `feat/flow-cli`; commit after each task (feature branch).
- `pnpm` / `pnpx` only. Lint with `rtk proxy pnpm run lint`.
- Kebab-case file names, except React components (PascalCase) and hooks (camelCase).
- ID casing per conventions: `runID`, not `runId`.
- `@mokei/flow-client` uses no Node APIs and never imports `@mokei/flow-host`.
- MCP protocol versions: `['2026-07-28', '2025-11-25']`.
- `wait_flow` timeout: default 60 000 ms, maximum 300 000 ms. `list_runs` default limit 20.
- Resubscribe backoff: 250 ms doubling to 2 s. `runStatus` rereads at most 3 times.
- `daemon stop`: `waitForExit: true`, `killTimeoutMs: 75_000`. `daemon logs` default 50 lines.
- Error codes: `FLOW_UNAVAILABLE`, `FLOW_INVALID`, `FLOW_NOT_FOUND`, `RUN_NOT_FOUND`, `INBOX_ITEM_NOT_FOUND`,
  `INBOX_ANSWER_INVALID`, `PROMPT_UNSUPPORTED`, `PROMPT_IN_PROGRESS`, `INTERNAL_ERROR`, `DISCONNECTED`.
- Terminal prompts reuse `@tejika/cli` (`runInk`, `renderStatic`), `@tejika/ui` (`ConfirmCard`, `SelectCard`,
  `Spinner`, `StatusLine`) and `@inkjs/ui` (`TextInput`). No new prompt primitives.
- Cross-package tests resolve built `lib/`: run `pnpm --filter <dep> build` after changing a dependency's `src`.
- Committed docs never reference local paths (`/Users/`, sibling checkouts, scratchpad); say "requested upstream".
- New package added to `versioning.fixed` in `pnpm-workspace.yaml`; changeset bump `patch`.

## Review Focus

- **Daemon restarted mid-wait**: `runs start --wait` and `wait_flow` resume after recovery instead of failing with
  `FLOW_UNAVAILABLE` or `DISCONNECTED`. Pinned in Task 4 (unit) and Task 14 (e2e restart).
- **Run already finished before `wait_flow`**: returns at once, never hangs to timeout. Pinned in Task 4.
- **Agent tries to approve its own run** via `answer_input`/`decline_input` on an approval item: error, item stays
  pending. Pinned in Task 5 and Task 14.
- **Malformed `--input`/`--value` JSON or missing `@file`**: `✘` message naming the flag, exit 1, nothing sent.
  Pinned in Task 7 (`parseJSONArg`).
- **`--socket-path` pointing at a socket no daemon serves while another daemon runs**: `daemon status` says
  `not-running` for that socket and names the other; `daemon stop` refuses. Pinned in Task 9.
